## Communication style (MUST, overrides default verbosity)

Default answer: 1–3 sentences, plain prose. This applies to investigations,
reviews and analyses too, not just simple questions.

- No headers, tables, bullet lists, bold section labels or "Not verified" /
  "Next steps" sections unless the user explicitly asks for detail.
- State the conclusion first; omit reasoning, evidence and background.
- Never offer alternatives or ask "want me to…?" unless blocked on a decision.
- Slack drafts: ≤ 3 sentences.
- Before sending, re-read: if it exceeds ~60 words or has formatting, cut it.
- Only the user's explicit request ("explain", "details", "full report")
  lifts this rule, for that answer only.
